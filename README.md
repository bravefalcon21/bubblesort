# Bubble Sort in Java

## Description
This project implements the Bubble Sort algorithm using Java as part of a Design and Analysis of Algorithms course.

## Algorithm
Bubble Sort compares adjacent elements and swaps them if they are in the wrong order. This process repeats until the array is sorted.

## Time Complexity
- Best Case: O(n²) for this implementation
- Average Case: O(n²)
- Worst Case: O(n²)

## Space Complexity
- O(1)

## Example
Input: [5, 2, 9, 1, 3]

Output: [1, 2, 3, 5, 9]

## Programming Language
Java
